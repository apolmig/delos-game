# Republic of Talos / credits

Game authored by Miguel Guerrero: https://miguelguerrero.eu

ERA: Capability, Deployment, Effect: https://miguelguerrero.eu/agencytransfer/

- Original fictional world and character sculptures created locally with Blender 5.2.2 LTS. Editable Blender source is included.
- Three.js 0.180.0, MIT license, assets/THREE-LICENSE.txt.
- Barlow font, SIL Open Font License, assets/FONT-LICENSE.txt.
- Three optional incident films are AI-generated fictional dramatizations from the existing Talos teaser, originally generated with Seedance 2.0 Fast through ElevenLabs Creative Studio. The existing footage is reused in this edition.
- Music: Night Session, an original 72 BPM, 160-second lofi composition created for Republic of Talos. Electric-piano synthesis, bass, brushed percussion and room echoes; no third-party samples or recordings. Reproducible with compose-score.py and ffmpeg.
- Sound effects: original short procedural cues generated locally with Web Audio.
- Eighteen cinematic incident illustrations reuse the existing Talos AI-generated image collection. Compressed web copies and per-file provenance are listed in assets/scenes/manifest.json.
- Research references and limits are in RESEARCH.md and in the game. Citations imply no endorsement.

The game contains no official Civilization assets, branding, code or affiliation. Game progress remains local. The web edition loads assets from its own host. The standalone PLAY.html includes all assets and needs no network. Only explicitly opened research links visit external sites. No private source documents or credentials are included.

- Nine new human-impact stills were created with built-in imagegen for edition 4. Prompts, generation filenames and output hashes are in assets/scenes/outcomes-manifest.json. They depict fictional people and situations, not documented incidents.
- Five additional existing moving scenes were compressed for the opening, horizon and ending films. Provenance and generation IDs are in assets/cinema/manifest.json. Total distinct footage scenes: eight.
